# Portfolio

Point de départ minimaliste pour construire votre portfolio avec Next.js et Tailwind CSS.

## Démarrage rapide

```bash
npm install
npm run dev
```

L’interface est disponible sur [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app/layout.tsx` : gabarit racine et métadonnées du portfolio.
- `src/app/page.tsx` : page d’accueil à personnaliser.
- `src/app/globals.css` : styles globaux et reset minimal.
- `public/` : placez vos images, icônes et autres assets statiques.

## Checklist avant commit

- Vérifier les erreurs avec `npm run lint`.
- S’assurer que `npm run build` passe sans avertissement bloquant.
- Documenter vos tests manuels dans la description de la PR.

Bonne construction !
